# ループオセロ

上下左右の端がつながった盤面で遊ぶオセロのプロトタイプです。人対人と人対CPUを選べます。
端を越えた石の探索も通常のオセロと同様に挟み判定に含めます。

## 起動方法

```sh
python -m pip install -r requirements.txt
python game.py
```

## 操作

- タイトル画面で「人 対 人」または「人 対 CPU」を選びます。CPU戦では黒がプレイヤー、白がCPUです。
- 置ける場所をクリックしてプレイします。
- 薄緑の点が現在の合法手です。
- 置ける場所がない場合は自動でパスします。両者とも置けなくなると終了します。
- `R` キーで最初から遊び直せます。
